OpenChip

Describe the module you need

OpenChip turns the description into a reviewable contract, an independent reference model, Verilog RTL and tool-backed evidence. Be precise about ports, reset behaviour and what happens on each clock.

Type / at the start of the box for commands: /resume, /settings, /help.

Activity

Settings

Bring your own key. Keys are stored only in ~/.config/openchip/keys.env on this machine.

Toolchain

Sessions

Newest first. Enter opens a session. A session whose last run stopped before finishing can be resumed from its last checkpoint.

Help

/resume
List every session, open one, or restart a run that stopped before finishing.
/settings
Provider, model, API key and the local toolchain check.
/help
This list.
Keyboard
Arrow keys and Enter drive the command palette, Escape closes it. Tab reaches every control, Escape closes any dialog.
What a run does
Intake, review, an independent reference, RTL, verification against the reference, then sign-off. Every claim in the report is tied to a tool result.
Withheld
OpenChip refuses to accept a design it could not verify, and says which check was missing.

Request a change

A change creates a new contract version, invalidates the previous evidence and verifies again.
