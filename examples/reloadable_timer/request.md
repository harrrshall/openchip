Implement Verilog module reloadable_timer with exactly these ports: input clk, input load, input [9:0] data, output tc. On each rising clk edge, load=1 sets the internal unsigned 10-bit count to data and takes priority over counting, including while already active or at zero. With load=0, decrement a nonzero count by one; a zero count holds zero. tc is combinational and equals 1 exactly when the internal count is zero; otherwise it is 0. There is no reset and the initial count is unspecified. A load establishes the count. After loading N, tc becomes 1 after N further rising edges with load=0, and stays 1 until a subsequent nonzero load. Do not add ports or initialize a hardware register.
