Implement synthesizable Verilog-2001 module uart_tx8n1 with parameter integer CLKS_PER_BIT=4 (legal values at least 2). Inputs clk, reset, start (each one bit), data[7:0]. Outputs tx, busy, done (each registered one bit). All sequential logic uses positive clk edges. reset is synchronous active-high and has priority: tx=1, busy=0, done=0, discarding any frame.
When idle, tx=1 and busy=0. A high start sampled on an idle rising edge latches data and starts an 8N1 UART frame: tx immediately becomes start bit 0 and busy becomes 1. The frame consists of one start bit, eight latched data bits least-significant-bit first, and one stop bit 1. Each of these ten bits lasts exactly CLKS_PER_BIT complete clock periods. For a frame accepted at edge k, the start bit occupies edges k through k+CLKS_PER_BIT-1 inclusive; data bit 0 starts at k+CLKS_PER_BIT; the stop bit starts at k+9*CLKS_PER_BIT. At edge k+10*CLKS_PER_BIT, return to idle and assert done=1 for exactly that one cycle. done is zero at every other edge. Ignore start and data changes while busy, including a start high on the completion edge. A later idle edge may accept the next frame. Do not add ports, asynchronous reset, initial blocks, or change this timing.
